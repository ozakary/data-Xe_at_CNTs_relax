# θ=0 Reference Relaxation

The original, single-orientation (SWCNT axis parallel to B<sub>0</sub>) relaxation calculation. Superseded by [`powder_averaged_relaxation/`](../powder_averaged_relaxation/) as the reported methodology, kept for direct comparison against the powder-averaged results (see `results_summary.csv`'s `T1_old_s`/`T2_old_s` columns, generated by [`run_orchestration_and_results/collect_results.py`](../run_orchestration_and_results/collect_results.py)).

## Scripts

### [`step3_spectral_density_and_relaxation.py`](./step3_spectral_density_and_relaxation.py)
Fits the pooled θ=0 TCF (sum of one or two exponentials), obtains the SDF analytically, and computes T<sub>1</sub>, T<sub>2</sub> at θ=0 via the Redfield expressions.

```bash
python step3_spectral_density_and_relaxation.py \
    --tcf ./cnt_10_0_u23_Xe4_10ns_tcf.npz \
    --fit-max-lag-ps 1000 \
    --b0-fields 9.4 14.1 \
    --out ./cnt_10_0_u23_Xe4_10ns_relaxation.npz \
    --plot ./cnt_10_0_u23_Xe4_10ns_fit.png
```

### [`step4_per_track_uncertainty.py`](./step4_per_track_uncertainty.py)
Fits each tracked Xe atom's own θ=0 TCF independently and reports the standard error of the mean across atoms as the uncertainty on T<sub>1</sub>, T<sub>2</sub>.

```bash
python step4_per_track_uncertainty.py \
    --tcf ./cnt_10_0_u23_Xe4_10ns_tcf.npz \
    --fit-max-lag-ps 1000 \
    --b0-fields 9.4 14.1 \
    --out ./cnt_10_0_u23_Xe4_10ns_relaxation_per_track.npz
```

Run after [`preprocessing_and_tcf/`](../preprocessing_and_tcf/), independent of [`powder_averaged_relaxation/`](../powder_averaged_relaxation/).
